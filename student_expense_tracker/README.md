# Student Expense Tracker

A beginner-friendly college mini-project built with HTML, CSS and vanilla JavaScript.

## Features
- Add expenses with name, amount, category and date
- View total spending and current-month spending
- View spending breakdown by category
- Search expenses and filter by category
- Delete individual expenses or clear all records
- Automatically save data in browser LocalStorage

## How to run
1. Extract the ZIP file.
2. Open the `student_expense_tracker` folder in Visual Studio Code.
3. Open `index.html` in your browser. You can also use the VS Code Live Server extension.
4. Add an expense to start using the tracker.

## Technologies
- HTML5: page structure
- CSS3: responsive design and styling
- JavaScript: calculations, filtering, chart and application logic
- LocalStorage: browser-side data persistence

## Backend and database note
This beginner version does not use a separate server-side backend. JavaScript handles the application logic in the browser, and LocalStorage stores the records on that device/browser. For a project that requires a real backend and database, a server such as Node.js or PHP and a database such as MySQL can be added later.

## Project structure
- `index.html` — application page
- `style.css` — styling and responsive layout
- `script.js` — expense operations and LocalStorage
